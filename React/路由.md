> <h2 id="BILI_VIDEO_CONTENT路由跳转分析"><code>BILI_VIDEO_CONTENT</code> 路由跳转分析</h2>

`ROUTE_PATH.BILI_VIDEO_CONTENT` 最终跳转到的页面组件类是 `HGBiliContentPage`，定义位置：

```text
src/pages/bilibili/hg_bili_content_page.jsx:14
```

核心路由关系如下：

```jsx
BILI_CONTENT: "/bilibili/content/:contentType/:contentKey",
BILI_VIDEO_CONTENT: "/bilibili/content/video/:contentKey",
```

- `BILI_CONTENT`：注册在 React Router 中的通用动态路由。
- `BILI_VIDEO_CONTENT`：生成视频页面 URL 时使用的具体路径模板，不单独注册组件。

> <h3 id="路由匹配原理">路由匹配原理</h3>

`src/manager_antd/router/hg_router.jsx:95-98` 注册的是通用路由：

```jsx
{
  path: ROUTE_PATH.BILI_CONTENT,
  element: <HGBiliContentPage />,
}
```

即：

```text
/bilibili/content/:contentType/:contentKey
```

当 `handleVideoClick` 生成 `/bilibili/content/video/123` 时，会匹配上述动态路由，参数对应关系为：

```text
contentType = "video"
contentKey  = "123"
```

因此，不需要单独注册 `ROUTE_PATH.BILI_VIDEO_CONTENT`。

> <h3 id="跳转过程">跳转过程</h3>

`src/pages/bilibili/hg_bili_douga_page.jsx:113-121`：

```jsx
handleVideoClick = (video) => {
  this.props.navigate(
    generatePath(ROUTE_PATH.BILI_VIDEO_CONTENT, {
      contentKey: encodeURIComponent(video.id),
    }),
    {
      state: { video },
    },
  );
};
```

执行过程：

1. `ROUTE_PATH.BILI_VIDEO_CONTENT` 提供路径模板 `/bilibili/content/video/:contentKey`。
2. `generatePath()` 将 `video.id` 填入 `:contentKey`。例如 `video.id = "BV123"` 时，生成 `/bilibili/content/video/BV123`。
3. `this.props.navigate()` 执行页面跳转。
4. React Router 使用生成的 URL 匹配通用路由 `/bilibili/content/:contentType/:contentKey`。
5. 匹配成功后渲染 `<HGBiliContentPage />`。

`navigate` 由 `src/utils/WithRouter.jsx:11-16` 中的 `withRouter` 注入：

```jsx
function withRouter(Component) {
  return function WrappedComponent(props) {
    const navigate = useNavigate();
    const location = useLocation();

    return <Component {...props} navigate={navigate} location={location} />;
  };
}
```

`BiliDougaPage` 导出时经过该函数包装：

```jsx
const WrappedBiliDougaPage = withRouter(BiliDougaPage);
export default WrappedBiliDougaPage;
```

因此，类组件可以通过 `this.props.navigate(...)` 调用 React Router 的 `navigate`。

`HGBiliContentPage` 属于 `HGTopNavLayout` 的子路由，最终通过 `src/manager_antd/page_modules/home/hg_top_nav_layout.jsx:299` 中的 `<Outlet />` 显示。

> <h3 id="页面如何显示播放器">页面如何显示播放器</h3>

`HGBiliContentPage` 没有直接使用 `useParams()`，而是在 `getRouteContent()` 中手动解析 URL。

`src/pages/bilibili/hg_bili_content_page.jsx:19-25`：

```jsx
getRouteContent = () => {
  const pathParts = (this.props.location?.pathname || "")
    .split("/")
    .filter(Boolean);

  return {
    contentType: pathParts[2] || "channel",
    contentKey: decodeURIComponent(pathParts.slice(3).join("/")) || "popular",
  };
};
```

对于 `/bilibili/content/video/BV123`，拆分结果为：

```js
["bilibili", "content", "video", "BV123"]
```

最终得到：

```js
{
  contentType: "video",
  contentKey: "BV123",
}
```

随后在 `src/pages/bilibili/hg_bili_content_page.jsx:122-124` 判断内容类型：

```jsx
{contentType === "video"
  ? this.renderVideo(contentKey)
  : this.renderChannel(contentKey)}
```

因为 `contentType === "video"`，所以调用 `this.renderVideo("BV123")`，并渲染播放器组件：

```jsx
<HGVideoPlayerPage
  video={video}
  relatedVideos={relatedVideos}
  onVideoClick={this.handleVideoClick}
/>
```

完整组件链路：

```text
BiliDougaPage.handleVideoClick
    ↓
generatePath(BILI_VIDEO_CONTENT)
    ↓
/bilibili/content/video/:contentKey
    ↓
匹配 BILI_CONTENT
/bilibili/content/:contentType/:contentKey
    ↓
HGBiliContentPage
    ↓
contentType === "video"
    ↓
renderVideo(contentKey)
    ↓
HGVideoPlayerPage
```

> <h3 id="state-video的作用"><code>state: { video }</code> 的作用</h3>

跳转时通过路由 `state` 传递完整视频对象：

```jsx
{
  state: { video },
}
```

目标页面通过 `this.props.location?.state?.video` 读取。具体位于 `src/pages/bilibili/hg_bili_content_page.jsx:79-81`：

```jsx
renderVideo = (videoId) => {
  const video = HGBiliContentPageVM.getVideo(
    videoId,
    this.props.location?.state?.video,
  );
};
```

这样目标页面可以直接使用列表页传入的视频对象，不需要立即根据 `videoId` 再请求一次详情。

刷新页面时，路由 `state` 存在丢失风险，因此 VM 提供本地数据兜底：

```jsx
static getVideo(videoId, routeVideo) {
  if (routeVideo) return routeVideo;

  return (
    HOT_VIDEOS.find((item) => String(item.id) === String(videoId)) ||
    HOT_VIDEOS[0]
  );
}
```

> <h3 id="结论">结论</h3>

没有在 `hg_router.jsx` 中看到 `BILI_VIDEO_CONTENT` 对应的组件，是因为它不是独立路由，而是 `BILI_CONTENT` 通用动态路由的具体形式：

```text
BILI_VIDEO_CONTENT:
  /bilibili/content/video/:contentKey

能够匹配：

BILI_CONTENT:
  /bilibili/content/:contentType/:contentKey
```

- 最终页面组件：`HGBiliContentPage`
- 最终播放器组件：`HGVideoPlayerPage`
